## 作業の進め方

1. [RIGM 基本仕様](../RIGM仕様.md) と [プロジェクトの現状](../note.md) を読む。
2. 対象が原画の分解なら [パーツ分解](制作手順/パーツ分解.md)、新しい表情・姿勢なら [差分作成](制作手順/差分作成.md) を読む。
3. [学習記録一覧](学習記録/README.md) から、対象に近い例の条件・失敗理由・未確認項目を確認する。
4. 現在の文書から入力と識別子を取得し、対象だけを加工・追加・置換する。
5. RIGM 保存後にも検証し、[検証と学習記録](制作手順/検証と学習記録.md) に従って次回へ残す。

## 再利用する処理

名前付きパイプの通信、JSON 要求・応答、素材交換ジョブ、画像パーツ・グループの追加、画像置換、属性変更、排他差分切替、切り出し・拡縮・透明余白除去、Undo / Redo を移植の基礎とする。
処理コードのコピー本体は `Source/Reference/AIArtToPSD` に揃っており、[コードの対応表](元資料/README.md) から参照できる。

原画の分解には元画素を保持した切り出し・対象外の透明化を使う。隠れた肌等の補完と、新しい表情・ポーズの作成には画像生成・編集を使う。
学習記録には、Codex が次の制作で参照する条件、プロンプト、加工方法、検証、評価を蓄積する。

## RIGM へ接続する範囲

元コードの PSD 読み込みは取り込み用に利用する。通常保存と交換ジョブの復帰用保存は、RIGM の読み書きへ接続する。
RIGM のパーツ ID・親 ID・表示順を保持し、画像とサムネイルを `.rigm` 内部へ保存する。
元の `layerId` や `add_layer` 等の呼び出し名は、移植時に RIGM パーツへ対応付ける。交換処理と RIGM 内部の座標系の違いもそこで変換する。
