**最新の通常経路は工程ごとの協働制作。** RIGMMaker.workflow.exe を使い、movie-workflow-status/run/next/back で台本→設定→音声→演技プレビュー→出力を進める。生成後はGUIと同じデータを調整し、明示的に次へ進む。一括制作は任意・互換用。新規FullHD、既存寸法・fps保持、今回fps未指定。[工程操作例](AI操作例.md)。動画APIは計41命令。

対象EXEは `RIGMMaker.workflow.exe`。編集仕様の原本 `RIGM_Maker_編集仕様.md` は変更していない。制作は保存済みRIGMを独立して読み込み、編集中のRIGM文書・手動役割・ロック・修正状態に書き込まない。既存RIGMのopen時分類、確認不要の工程進行、必須パーツ不足や破損の停止も維持する。

## 制作データと演技

`RIGM-MOVIE` formatVersion=1、拡張子 `.rigmovie`。セリフに安定したid、scene、speaker、本文、字幕、間、expression、motion、background、parameters、acting、音声参照とfingerprintを保存する。従来のactingなしファイルは既定値で読み込む。保存時にRIGM・WAV・LAB・背景を隣の `.assets` にコピーし、別名保存でも参照を移す。明示保存のみで、自動保存しない。

| acting項目 | 既定値 | 範囲・意味 |
| --- | ---: | --- |
| mouthMode / blinkMode | auto | auto=素材優先/不足時変形、assets=既存開閉素材、deform=変形 |
| mouthGain | 1 | 0～2、口パク強度 |
| lipLead | 0 | -0.3～0.3秒。正は先のPCMを参照 |
| blinkStrength | 1 | 0～1、瞬き強度 |
| blinkInterval | 3.7 | 0.3～30秒、瞬き間隔 |
| blinkDuration | 0.16 | 0.04～1秒、間隔以下 |
| blinkPhase | 0.73 | 0～30秒、セリフ内の瞬き位相 |
| headGain / bodyGain | 1 | 0～3、頭／上半身の動き |
| onset | 0 | 0～600秒、セリフ先頭からの演技開始 |
| duration | -1 | -1=間を含むセリフ終端、または0～660秒 |
| fadeIn / fadeOut | 0 | 0～60秒、演技窓の両端からのフェード |
| variants | [] | 保存済みRIGMのgroupIdと直下のpartIdの配列 |

演技窓と強度は口パク・瞬き・頭・上半身に適用する。口パクは実PCM振幅に基づき、セリフ後の間や範囲外では閉じる。variantsはそのセリフの間を含む区間で適用し、演技窓とは独立する。各グループは選択した子だけを表示し、必要な祖先グループも表示する。存在しないID・参照パーツ・直下でない候補・矛盾する入れ子選択はエラー。元文書の表示状態は変えない。parametersに明示した値は演技計算後に適用し、キャラクターの範囲へ制限する。

expressionはneutral／smile／serious／sad、motionはidle／still／nod／emphasis。現在のRIGMパラメータと実在素材を利用する。新しい表情画像、自然な側面顔、音素別の口形を生成したとは扱わない。

## 波形・時刻・ジョブ

WAVはPCM16 mono／stereoを検証して読み込み、48000Hz monoへ混合する。波形は実PCM全体のmin／maxを2048組の整数で表し、amplitudeScale=32768。発話・間と字幕の位置を同じタイムラインに表示し、クリックシーク、全体／10／30／60秒の表示範囲に対応する。

波形と混合キャッシュは音声fingerprint・WAV参照／更新情報・長さ・間で判定する。字幕やactingのみの編集では有効性を保持し、音声設定や間の変更では失効する。混合キャッシュは1件・最大32MiB。タイムライン時刻が変わらない停止中は連続再描画せず、プレビュー完了で全編集欄を更新しない。

音声・素材一覧・波形・プレビュー・出力は独立スナップショットのワーカーで実行し、同時ジョブは1件。途中取消後の再試行は清掃完了後に1回実行する。成功済み音声は保持し、本文やprojectIdが変わった古い結果は採用しない。接続／合成失敗で既存音声を置き換えない。通常処理に試験トーンへの代替はない。

## 共通パイプ

既存commandPipe、UTF-8 JSON封筒schemaVersion=1を使う。制作命令は `movie-` 接頭辞、計41命令。通常のRIGM編集43命令を維持する。制作編集には最新movie-statusのprojectIdとrevisionが必要。PowerShell送信器は省略された値を補い、明示された古い値は置き換えない。

- `movie-schema`：actingFields、cueFields、speakerFields、全命令の引数を取得。
- `movie-assets-refresh` → `movie-job-status` → `movie-assets {offset,limit}`：実在するグループ・子素材・パラメータを取得。一覧は既定20グループ、1ページ最大100。現在のGUI一覧は先頭20グループ。
- `movie-update-cue {id,acting:{...}}`：指定したacting項目だけ変更し、省略項目を保持。範囲違反は編集全体を拒否する。
- `movie-waveform-refresh` → `movie-job-status` → `movie-waveform`：実音声波形とcurrentを取得。
- `movie-timeline`、`movie-seek {time}`、`movie-preview {time,path}`：発話と字幕の同じ時刻を表示。
- `movie-save {path}`、`movie-open {path}`、`movie-undo`、`movie-redo`、`movie-export {path}`：保存・再開・編集履歴・動画出力。

完全な引数は実行中の `movie-schema` が基準。[共通パイプ手順](../パイプ/README.md)も参照する。

## 出力設定・進捗・検証範囲

projectに`encodeProfile`（既定balanced）を保存する。`outputPreset`は寸法からdraft/hd/fullhd/customを導く。draft=640×360/15fps、hd=1280×720/30fps、fullhd=1920×1080/30fps。`movie-update-project`でpresetを指定した後、明示したwidth/height/fpsがあればその値を優先する。独自寸法はcustomになる。encodeProfileはfast/balanced/qualityで、範囲外は変更全体を取り消す。台本取込で省略された設定も保持する。

| encodeProfile | JPEG品質 | H.264設定 | スレッド |
| --- | ---: | --- | ---: |
| fast | 80 | veryfast / CRF23 | 4 |
| balanced | 90 | medium / CRF20 | 4 |
| quality | 95 | slow / CRF18 | 4 |

`movie-schema.outputPresets`で設定を取得できる。UIはサイズ・画質/速度の選択と設定適用、演技方式選択に対応し、共通セッションを使う。進捗描画は軽い描画と200ms間隔の表示更新を用い、再生時計とパイプを妨げない。

job-statusは`phase`（prepare-character/prepare-audio/render/encode）、`phaseCompleted`、`phaseTotal`、`elapsedSeconds`、`remainingSeconds`を返す。remainingSeconds=-1は未算出、完了時0。残り時間は現在の工程だけの概算。`encoderPeakPrivateBytes`、`encoderPeakWorkingSetBytes`、`exportStagingPeakBytes`、`encoderProcessId`、`encoderExited`も返す。終了後は経過時間を固定する。

AVIはMJPEG＋48000Hz PCM16 mono。MP4はユーザーが選んだ既存ffmpeg.exeによるH.264/AACで、一時AVIの2GB制限を継承する。既存出力を上書きせず、最終ファイルへの移動直前にも置換を許可しない。取消・変換エラー時はこのジョブが起動した子だけを終了し、所有する一時AVI/MP4/ログを整理する。ユーザーアプリを強制終了しない。

実素材試験は、保存済みきりたんの独立コピー、44レイヤー、コピーだけに準備した6ボーン/5×5メッシュ、既存の6ポーズ・眉・開閉目口、**速度優先、1920×1080/30fps/180秒、60セリフ/6シーン、明示的テスト音**。独立検証EXEの所要時間386.265秒、MP4 27,806,186バイト。アプリのPrivate Bytes観測ピーク116,699,136バイト、FFmpeg子328,441,856バイト、AVI＋MP4一時ファイル合計観測ピーク582,269,690バイト。各メモリ値は別々のピークで、一時容量にログは含まない。

全5400フレームと全AAC音声を独立復号し、時刻の連続性、開始0/提示180秒、全60区間の音と無音を確認した。短いAVI/MP4、保存再開、UI/共通パイプ、描画/圧縮の取消・子終了・既存出力保持を含め、最新系列の成功判定は重複加算なしで774項目。最終Win64 Debug/Releaseの警告・エラー・ヒントは0。[利用手順と測定詳細](README.md)と[提供版の検証JSON](../../Win64/Validation/fullhd-release-verification.json)を参照する。

素材にない自然な左右の顔向きや新しい表情は未対応。元素材にはボーン/メッシュがなく、その準備をユーザー素材へ自動反映していない。実VOICEVOXの修復・日本語音声品質は未承認/未検証。物理デスクトップの手操作、実Pro HID、複数DPIは未検証。生成画像とVCL PaintTo画像を画像ツールで実見した範囲を検証JSONへ記録する。


## guided版の案内と事前診断

`outputTarget`は新しいAVI/MP4出力先としてproject JSONと保存ファイルに保持する。`movie-export`はpath省略時にoutputTargetを用いる。既存ファイルを上書きしない。

`movie-preparation {outputPath?}`は読取応答。steps[5]、issues（最大20件、totalIssues）、nextAction/nextCommand/nextArgs/nextArgsRequireUserValues、engine、availableStyles、capabilities、estimate、audioPending、canGenerateAudio/canPreview/canExport、diagnosticsCurrent/diagnosticsBusy、previewCurrentを返す。issuesはcode/message/nextAction/scope/subjectId/blocking。`safe-acting`はUI操作識別子で、機械用nextCommandは実在する`movie-update-cue`、nextArgsはauto/auto/variants解除などの編集内容。仮のID・パス・声はschemaと実データから置換する。編集前に最新movie-statusのprojectId/revisionが必要。

主なissueコード: script_empty、engine_unchecked、engine_unavailable、speaker_unavailable、audio_pending、character_none、material_unchecked、material_invalid、motion_unavailable、acting_unavailable、background_missing、output_missing、output_exists、output_format、ffmpeg_missing、disk_space_low、output_drive_unavailable、output_path_invalid、avi_staging_risk。

`movie-diagnostics-refresh`は別の取消可能な読取ジョブを起動する。`movie-job-status {scope:"diagnostics"}`で進捗確認、`movie-job-cancel {scope:"diagnostics"}`で診断だけ、scope=mainで制作だけ、省略/allで両方を取消す。診断成功は診断完了を意味し、engine.connectedとissuesを確認する。実音声生成・修復・自動保存は行わない。engine接続成功は話者一覧取得まで。realSpeechVerified=falseは診断が実音声を検証していないことを示す。

診断結果はエンジンURL・素材パス/サイズ/更新時刻・cue ID/口と目の方式/variantsで無効化する。古い診断結果を変更後の素材に適用しない。openはキャッシュとプレビュー準備状態をクリアして再診断する。診断は制作Busyを立てず、入力編集を許可する。例文はschema.examplesにfictional_example/structure_templateとして公開し、GUIでは明示的に選んだ場合だけ入力欄へ表示する。
