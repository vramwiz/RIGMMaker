# Codex / dotとGUIによる工程ごとの動画制作

最新版はルートの **`RIGMMaker.workflow.exe`**。通常は、Codexが台本・設定・音声・演技プレビュー・動画出力の各工程をパイプで作成し、GUIと同じデータを調整してから明示的に「次へ」で進める。[工程ごとの操作例](AI操作例.md)を参照。生成完了だけで自動通過せず、毎回の確認済みフラグも不要。

新規制作はFullHD1920×1080、fpsは既存FullHDプリセットの30を基本にする。今回fpsはユーザー未指定。既存の寸法・fps・素材・声・演技・出力設定は勝手に変更しない。[一括制作API](AI一括制作例.md)は任意・互換用。

GUIの通常操作は現在工程・結果プレビュー・必要な編集・結果作成・次へ・戻る。既存のデバッグ詳細と個別操作は残す。以下はその個別操作の説明であり、自動の工程進行手順ではない。
## 補助GUIを手動で操作する場合

1. 制作画面のキャラクター選択アイコンから、保存済みの`.rigm`を選ぶ。編集中のRIGMを直接書き換えず、保存した素材を制作側で読み込む。「テスト用キャラ」は表示確認用の自作サンプル。
2. 幅・高さ・fps、タイトル、VOICEVOX接続先を設定して「設定を適用」を押す。標準の接続先は`http://127.0.0.1:50021`。偶数寸法160～3840×120～2160、1～60fpsに対応する。
3. 左側に台本を入力し「入力した台本を取り込む」を押す。上部の取込アイコンからUTF-8のテキストまたはJSONも読み込める。
4. VOICEVOXを起動し、話者一覧取得アイコンを押す。セリフを選択し、右側で台本上の話者にVOICEVOXの音声を割り当て、「音声設定を適用」を押す。最小ウィンドウでは右側を下へスクロールする。
5. 音声生成アイコンを押す。本文・話者・音声設定が変わったセリフだけを生成する。失敗理由と進捗は下部に表示される。取消後は再試行でき、途中まで成功した音声は保持する。
6. 右側で字幕、セリフ後の間、表情ポーズ、動作、背景画像を調整し、「セリフを適用」を押す。字幕だけの変更は音声を再生成しない。長い字幕は時間に応じてページを切り替える。
7. 音声生成後に波形取得アイコンを押す。下部のタイムラインには発話と間・字幕・実音声の波形を表示する。波形のクリックまたはシークバーで時刻を選び、プレビューまたは再生アイコンを押す。再生アイコンを再度押すと停止する。音声未生成のプレビューは推定時間で表示し、書き出しにはすべての発話の音声が必要。
8. 保存アイコンで`.rigmovie`を保存する。隣の`.assets`フォルダーに音声・LAB・背景・RIGM素材をコピーするため、ファイルとフォルダーを一緒に移動する。別の保存先への保存でも資産をコピーする。開き直すと保存済み状態・時刻0から再開する。
9. 出力アイコンで新しいAVIまたはMP4のファイル名を指定する。既存の動画は上書きしない。

## 台本例

```text
# 紹介
narrator:こんにちは。これは自作の短い作品の紹介です。
narrator:色づかいと、静かな雰囲気が気に入っています。
# まとめ
narrator:最後まで見ていただき、ありがとうございました。
```

`#`から始まる行はシーン名。`話者ID:本文`または`話者ID：本文`で話者を指定する。話者指定のない行は`narrator`。空行は無視する。本文と表示字幕は後から別々に編集できる。JSONのフィールドは共通パイプの`movie-schema`で取得できる。

## 出力設定と進捗

上部の「出力サイズ」で下書き・HD・フルHDを選び、「出力の画質と速度」で速度優先・標準・画質優先を選んでから「設定を適用」を押す。選択しただけではプロジェクトを変更しない。カスタムでは幅・高さ・fpsを入力する。設定は保存・再開と共通パイプで保持される。

| 出力サイズ | 幅×高さ | fps |
| --- | ---: | ---: |
| 下書き | 640×360 | 15 |
| HD | 1280×720 | 30 |
| フルHD | 1920×1080 | 30 |
| カスタム | 入力値 | 入力値 |

速度優先は圧縮を軽くし、画質優先は高い画質で圧縮するため時間と一時容量が増える。MP4は「映像の作成」から「動画の圧縮」へ進む。画面下部に工程進捗・経過時間・**現在の工程の残り時間**を表示する。残り時間は概算で、描画中の値に後続の圧縮時間は含まない。取消アイコンで処理を止められる。既存出力は上書きしないので、新しいファイル名を指定する。

右側の演技欄には「口パクの方式」「瞬きの方式」がある。「自動（素材を優先）」は既存の開閉素材を使い、対応差分がない場合は変形する。「既存素材を切替」は対応する開閉グループがあるキャラクターで使う。「変形」は形状を動かす方式。回転前の座標で変形するため、頭を傾けたときも顔の部品が追従する。素材を使う方式では選択画像を過度に伸ばさない。元RIGMの画像・表示状態は変えない。
## AVIとMP4

AVIはアプリ単体でMJPEG映像と48000Hz PCM16 mono音声を出力する。MP4は「MP4用の既存FFmpegを選ぶ」アイコンで手元の`ffmpeg.exe`を設定してから、出力ダイアログのMP4形式を選ぶ。H.264/AACで変換する。FFmpegの実行ファイルと同梱DLLを同じ構成のまま保持する。アプリからダウンロードやインストールは行わない。

この環境で検証に使った既存FFmpegは`C:/Users/zan12/Downloads/ffmpeg-8.1.1-full_build-shared/ffmpeg-8.1.1-full_build-shared/bin/ffmpeg.exe`。FFmpegのパスは制作ファイルに保存するが、実行ファイル自体は`.assets`へコピーしない。別のPCでは選び直す。

MP4は一時AVIを作成してから変換するため、AVIの2GB上限を共有する。表情と動作は現在のRIGMパラメータと、保存済み素材の切替による演出。新しい顔向きや表情画像を生成する機能は含まない。

## セリフ別の演技と保存済み素材

セリフを選び、右側を下へスクロールすると「セリフ別の演技」がある。口パク・瞬き・頭・上半身の強度、瞬きの間隔・時間・位相、口パクの先行時間、演技の開始・長さ・フェードを設定し、「演技を適用・プレビュー」を押す。音声の再生成は不要。編集は未保存になり、Undo／Redo・保存・開き直しに対応する。

開始時刻はそのセリフの先頭からの秒数。演技時間の-1は、セリフ後の間を含めた終端までを意味する。正の口パク先行時間では、少し先の音声振幅を参照する。発話後の間は口を閉じる。自然な口形の種類を音素から生成する機能ではない。

「既存キャラクター素材一覧を取得」アイコンで、保存したRIGMのグループと子素材を読み込む。互いに切り替える候補として用意されたグループを選び、表示候補を選んで演技を適用する。同じグループの他の子はそのセリフ中に非表示になる。通常の部位集合を選ぶと必要な他の部位も非表示になるため、素材の構成に合わせて選ぶ。

元RIGMの表示状態や画像は書き換えない。「保存済みの表示状態」または「このセリフの素材選択を解除」で元の状態に戻す。素材一覧は制作ファイルを開いた後に取得し直す。存在しない素材IDや、入れ子グループの矛盾した選択はプレビュー／出力のエラーになる。サンプルに存在しない表情候補を用意済みとは表示しない。フィールドと共通パイプの詳細は[制作仕様](仕様.md)を参照する。

## 次の改善候補

1. 台本の取込からキャラクター・話者・演技・出力まで、必要な操作と現在地を一続きで案内する。
2. 作業開始時に音声エンジン、FFmpeg、素材のボーン/メッシュ、開閉差分と空き容量をまとめて診断し、修正箇所を示す。

## 制作案内と読取事前診断

上部に「台本取込 → 話者・キャラ・素材 → 音声生成 → プレビュー → 出力」と現在の準備状態を表示する。「次の操作」は必要な取込・設定・音声生成・プレビュー・出力へ進む。最初の台本欄は空で、ユーザーの台本を作成・評価しない。

「準備を診断」はVOICEVOXの話者一覧と保存済みRIGMを別の読取ジョブで確認する。診断中も台本・設定を編集できる。右側を診断欄までスクロールし、不備のコード、修正すべき内容、利用できる演技、概算時間、一時容量、空き容量を表示する。編集途中の未適用入力を診断完了時に書き換えない。エンジンの起動・修復、素材の変更、自動保存は行わない。取消アイコンで診断と制作処理を取り消せる。

1. 自分の台本を貼り付けて「次の操作」または「入力した台本を取り込む」を押す。
2. 保存済みRIGMを選び、接続先・寸法・画質を設定する。「準備を診断」で実際の話者一覧を取得し、話者ごとの声を選んで「音声設定適用」を押す。
3. 「次の操作」で音声を生成する。字幕・演技の変更では既存音声を再生成しない。失敗した場合は具体的な理由を表示し、成功済みの音声を保持する。
4. 「次の操作」でプレビューする。素材にない口・目の切替を指定している場合は「使える演技へ戻す」で選択中セリフの口/瞬きを自動、素材選択を解除し、ボーン/メッシュがない場合は頭/上半身の強度を0にする。元素材は変更しない。
5. 上部の「新しい出力先」に未使用の絶対パス（.avi/.mp4）を設定して「設定適用」を押す。MP4は既存FFmpegを選ぶ。「次の操作」で出力する。既存出力を上書きせず、追加の必須確認は挟まない。
6. 保存アイコンで`.rigmovie`を保存し、再度開いて診断する。出力先・演技・音声参照を保持して再開する。同じ接続先・話者・本文の保存済み音声が有効なら、エンジン停止中でもプレビュー・出力できる。

台本例の選択欄には「架空の短い紹介例」と「3分紹介の構成テンプレート」がある。「選択した例を入力欄へ表示」を明示的に押した場合だけ、入力欄へ表示する。取り込みは別の操作。3分テンプレートは6区間の構成案で、【】の内容をユーザーが置換する。実音声の速度と間によって長さが変わり、180秒を保証しない。例文で既存の制作台本を自動置換しない。

## 利用上の制限と未検証

今回の依頼範囲で実装・回帰検証を残した項目はない。ただし、実VOICEVOXの起動不良があり、日本語の実音声生成と実音声での口パク品質は外部環境の未検証として残る。修復未承認のためインストール内容を変更していない。通常処理でテスト音を代替生成しない。

- 素材にない自然な横向き・後ろ向きや新しい表情画像は生成しない。既存画像の切替・変形を利用する。頭と上半身の動きにはボーンとメッシュの準備が必要。未準備素材でも静止表示と既存ポーズ差分は利用できる。
- MP4も一時AVIを経由するため2GB上限がある。サイズ・fps・尺を抑える必要がある。
- 診断の時間・容量は1080p/30fps/速度優先の保存済み基準からの目安。PC・素材に依存し、標準/画質優先の係数は未実測。書込権限とFFmpegの起動・コーデックは読取診断では試さず、実際の出力時にエラーを報告する。
- GUIの素材選択一覧は先頭20グループ。パイプの`movie-assets`はページ取得できる。
- 物理デスクトップの手操作、実Pro HID入力、複数モニターDPI、最大密度メッシュでの性能は未検証。画面確認は隔離したVCLフォームのPaintTo画像を閲覧した範囲。
