# RIGM 制作の検証と学習記録

制作ごとに、入力、指示、加工、配置、保持した情報、検証、評価、次回の改善を残す。
参考元で採用された条件は [学習記録一覧](../学習記録/README.md) から読む。

## 確認する内容

| 対象 | 確認内容 |
| --- | --- |
| 入力 | 元画像の実寸、RGBA、対象パーツと文書の識別子、作業開始時の版 |
| 最終 PNG | 実際に取り込む寸法と alpha、輪郭、背景の隙間、人物内部の白い部分、不要な光や汚れ |
| 配置 | 位置、サイズ、倍率、回転、基準点、透明余白除去後の位置補正 |
| 既存パーツ | 対象外の画素、ID、親、表示順、位置・回転・倍率、表示状態、不透明度、ロック状態 |
| 合成 | 市松と明暗背景で単独・合成を比較。差分切替と、必要なパーツ移動時の欠け・混入を確認 |
| 保存後 | `.rigm` を読み直し、パーツ情報、埋め込んだ画像・サムネイル、合成結果を検証 |

元画素の一致は、表示用の再描画画像だけで判断せず、対象 PNG や埋め込んだ画像の RGBA を直接比較する。
原画素の分離、AI による補完、新しい差分の生成では、画素の保持条件が異なるため、それぞれの対象と変更範囲を記録する。

## 記録の保存

新しい制作例は `制作支援/学習記録/RIGM/<日付と用途>/` に、必要になった時点で保存する。
[記録テンプレート](../学習記録/記録テンプレート.json) を使い、入力・最終 PNG・生成指示・配置・検証・RIGM 成果物への参照を記録する。
今後繰り返し使う一般的な判断は制作手順へ反映し、画像固有の座標・色判定・パーツ ID はその制作例に残す。

数値検証、アプリへ反映・保存、ユーザーの見た目の評価を別々に記録する。
未確認の項目には未確認と書き、参考元での採用を今回の RIGM 制作の採用と同一視しない。
失敗や条件付きの結果も残し、再試行時は入力と問題点を確認する。

## 交換と復帰

現在の文書から新しいジョブを取得する。過去の PID・パイプ名・ジョブ ID・文書 ID・パーツ ID を再送しない。
古くなった結果は識別子や版だけを書き換えて取り込まず、現在の状態から作り直す。
取込候補を一括検証し、成功後に適用する元処理と Undo の構成を活かす。
復帰用保存は RIGM に接続し、書き出し時点への復帰と最終成果物の保存を区別する。

本手順は移植後の運用方針。現在のアプリへのパイプ接続と RIGM 保存・再読み込みの実動作は未実装。
