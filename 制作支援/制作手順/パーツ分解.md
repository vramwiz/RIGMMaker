# RIGM 用パーツ分解

元の [PSD 立ち絵生成ルール](../元資料/AIArtToPSD/PSD立ち絵生成ルール.md) と [学習記録](../学習記録/README.md) を基にした制作手順。
元画像の画素・位置・解像度を保持して、RIGM の画像パーツとグループへ取り込む。

## 基本の顔パーツ

| パーツ | 保持するもの | 透明化・補完するもの |
| --- | --- | --- |
| ベース | 構図、髪、衣装、鼻、人物の陰影・ハイライト | 目・眉・口の跡を肌で埋める。人物外側と背景の隙間を透明化する |
| 両目 | 左右一組の目、白目、虹彩、まつ毛、必要な輪郭 | 髪・眉・不要な肌・他の部位を透明化する |
| 両眉 | 原画で見えている左右一組の眉 | 眉以外の髪・肌・目を透明化する |
| 口 | 唇、口内、明るい画素・ハイライト | 周囲の肌と他の部位を透明化する |
| 元画像 | 比較に使う原画全体 | 原本を保持し、取り込む場合は比較用の非表示パーツにする |

矩形は画像の範囲と配置を管理するために使う。その内部にも対象外の画素があるため、対象の輪郭外を alpha=0 にする。
左右の目・眉は一組のまま扱い、片側ごとに生成・拡縮して位置関係を変えない。

## 分解の手順

1. 元画像の実寸・内容と現在の文書を確認する。入力原本と既存パーツを保持する。
2. 新しい素材交換ジョブから対象の ID、画像、配置、表示状態、階層を取得する。
3. 原画の両目・両眉・口を元画素で切り出し、各パーツ以外を透明化する。別の絵では輪郭・遮蔽・色判定を決め直す。
4. ベースは目眉口を除去し、肌を自然につなぐ。白い服・靴・白目・ハイライトを背景と一緒に消さない。
5. 最終 PNG の RGBA、寸法、位置を検査し、ベース単独・パーツ単独・合成を市松と濃い背景で確認する。
6. 新規なら画像パーツと親グループを追加する。部分修正なら対象だけを置換し、確認済みの他パーツを保持する。
7. RIGM を保存し、再読み込みした画像・配置・階層・表示・不透明度と合成結果を照合する。
8. 見た目の評価と検証結果を [学習記録](検証と学習記録.md) に残す。

## 髪の分解と肌の補完

髪を独立させる場合、前髪に隠れた額・頭部も肌素体としてつなぐ。
肌単独、髪単独、元位置の合成、髪を動かした合成を比較し、透明な欠け・髪跡・境界の混色を確認する。
元の鼻・顎・首など保持できる画素を利用し、生成結果の倍率と位置は実寸・基準点から合わせる。
後ろ髪の不可視部分の補完は、額・頭部の肌補完と別に評価する。

採用済みの [肌素体と前髪境界の記録](../学習記録/AIArtToPSD/Sample/face_foundation_fix_20261002/learning_record.json) を参照する。

## 背景透過

生成プレビューに加え、実際に取り込む最終 PNG の alpha を確認する。元画素と補完画像を合成し直した後も透過を維持する。
人物外側、髪・脚・腕・指・リボン等の背景の隙間を点検し、人物内部の白い部分と分けて判断する。
RIGM の保存・再読み込み後にも対象画像と合成 alpha を確認する。
[背景透過の取り込み漏れの記録](../学習記録/AIArtToPSD/Sample/syncroh2_blonde_native_20261002/background-alpha-fix/learning_record.json) を再発防止に使う。

## 座標の扱い

元画像の切り出しと既存の交換 JSON は、左上を (0,0)、右を X 正、下を Y 正として bounds を扱う。
矩形は `[left,right) × [top,bottom)`。幅は `right-left`、高さは `bottom-top` とする。
透明余白を詰める場合、除いた左・上の余白の分だけ配置も補正する。

RIGM 内部の初期案はキャンバス中央を原点とする。幅 W・高さ H の画像上の点 (px,py) は、中央原点では `(px-W/2, py-H/2)` となる。
パーツの基準点や回転中心との対応は、RIGM モデルと描画の実装時に決める。元の bounds をそのまま中央原点の値として扱わない。
