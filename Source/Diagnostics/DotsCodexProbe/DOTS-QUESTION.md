# Dotsへの問い合わせ文

以下の内容をDots側へ渡して、対応可能な項目と必要な追加機能を確認してください。

## アクセス拒否を報告したDots側への追試依頼

Low整合性・実行ごとに異なるAppContainer SIDへ対応する試験モードを追加しました。利用者側で `Start-AppContainerProbe.ps1` を実行し、新しいフォームに表示される `connection.json` を取得してください。以前の接続情報は使わないでください。

そのJSONの `accessMode=appcontainer-test` と `requiresAccessToken=true` を確認し、全要求のルートへ `accessToken` を付けてください。値はそのJSONの `accessToken` を読みます。個別AppContainer SIDを申告・固定する必要はありません。同梱の `Send-ProbeCommand.ps1` は接続トークンを自動付与します。

最初にping、次に日本語echo、続いてimage.put/image.getの順で追試してください。接続段階のWindowsエラーと、接続後のJSONエラー（unauthorized等）を分けて返してください。接続トークンの値自体は回答へ載せないでください。ユーザーSID・Low整合性は同じで構いません。

---

WindowsのDelphi製クライアントアプリとDotsを連携したいです。まずテキストで試験し、次に画像の転送・認識・生成を試験します。

同梱の `README.md`、`PROTOCOL.md`、`protocol.json`、`examples.json`、`request.schema.json` を操作資料として読んでください。クライアントにはテスト用の1フォームアプリを用意しました。Dots側の実装にはまだ依存していません。

構成は次のとおりです。

```text
利用者の指示
  → Dots
  → （リモートの場合はクライアントPC上の補助プロセス）
  → 名前付きパイプ
  → テストアプリ
  → 専用Codex app-server API
  → テキスト回答／画像
  → クライアント側保存とDotsへの結果返却
```

ローカルの通信方式は、Windows名前付きパイプ、duplex / byte mode、UTF-8 JSON + LFです。1接続につき1要求・1応答で、応答後に接続を閉じます。接続先は起動時の `connection.json` に書き出します。同じPC・同じWindowsユーザーから接続する方式です。

次の項目について、**対応可能／追加実装が必要／非対応**を個別に回答してください。追加実装が必要なら、利用できる具体的な手段を教えてください。

1. 上記MarkdownとJSON資料を読み、その仕様に従って操作できますか。
2. Windowsクライアント側でEXEを起動し、`connection.json` を読めますか。
3. 名前付きパイプへJSONLを送受信できますか。直接接続が難しければ、同梱のPowerShell 7送信器 `Send-ProbeCommand.ps1` を実行できますか。
4. 日本語・絵文字・改行を保持して `echo` と `text.save` を実行し、保存結果を確認できますか。
5. `codex.start` の受付で得た `jobId` を保持し、毎回新しい要求idで `job.get` をポーリングして最終回答を受け取れますか。
6. 要求と応答の `id` を照合し、通信断の際は同じid・同じ要求で再送できますか。進捗・失敗・中止も利用者へ返せますか。
7. Base64によるPNG/JPEG/BMPの送受信と、復号後のSHA256照合ができますか。1枚4MiB、JSONフレーム8MiBを扱えますか。
8. リモートで動くDotsから、クライアントPCへ指示を届ける方法はありますか。ローカル補助プロセス、既存の常駐機構、認証付き中継など、利用可能な方法を教えてください。
9. アプリ未起動時の起動指示を受けるクライアント側機構を用意できますか。Dots自身の起動能力と、クライアント常駐機構が必要な範囲を分けて説明してください。
10. リモート側からクライアント側へのテキスト・画像配置について、現在の制約（実行場所、権限、ファイルサイズ、タイムアウト等）を教えてください。

この問い合わせ段階では、クライアントのパイプをネットワークへ直接公開することは想定していません。まずローカルでのテキスト往復を確認し、リモート経路は回答を受けて決定します。

回答は、項目番号・対応状況・方法・制限・不足情報が分かる表にしてください。不明な項目は推測で対応可能とせず、確認が必要と明記してください。
