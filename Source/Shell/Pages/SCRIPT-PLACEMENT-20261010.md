# 第4段階のキャラ配置（2026-10-10）

移動・拡縮は画面やL字のキャラ側ガイドからはみ出してよい。ドラッグ、パイプ、保存再開、動画編集で同じ比率座標を使い、工程の再表示やレイアウト変更だけで画面内へ戻さない。実際の動画では画面外の部分を描画範囲で切り取る。

画面外へ動かして操作できなくなった場合は、左のキャラ一覧で対象を選び「初期座標・サイズに戻す」を押す。現在のレイアウト、選択キャラの並び、元画像の縦横比から初期配置を再計算し、そのキャラの座標・幅・高さだけを戻す。左右反転・他のキャラ・台本は保持する。

パイプは既存の `app-script-set-placement` に `reset: true` を指定する。現在の `projectId`・`revision` と選択済みキャラの `path` が必要。比率座標の `x`・`y` は負値や1超を許可する。最小寸法はFull HD基準20px、有限数値で、既存の動画モデルに合わせ座標の絶対値と各寸法の上限を画面の4倍とする。

初期配置の計算は `DefaultScriptPlacement` で新規配置と復帰操作に共有する。ドラッグ計算は `RigmPlacementGeometry`、入力検証は `RigmScriptPlacementModel`、リンク先の動画キャラ検証は `RigmMovieComposition` が担当する。

検証入口は `Source/Psd/Validation/Run-ScriptOrderCheck.ps1 -CheckBackground`。専用作品と専用キャラでネイティブの画面外ドラッグ、拡大時の縦横比、パイプでの完全な画面外配置、L字での保存値保持、動画モデルへの接続、保存再開、GUIボタンによる4値の復帰・反転保持を確認する。複数DPIの検証は行わない。
