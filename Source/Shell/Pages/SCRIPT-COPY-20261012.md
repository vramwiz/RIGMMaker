# 台本一覧から必要な入力だけをコピー（2026-10-12）

台本一覧で保存済みの台本を選び、左から2番目の重なった用紙のアイコン「選択した台本をコピーして作成（本文・音声なし）」を押す。従来の新規作成・再開は維持する。コピーは別のUIDフォルダーへ保存して題名工程で開く。題名は元の入力を保持し、新しい作品に合わせて編集できる。元の台本は変更しない。

2026-10-11の指示と回答により、台本入力の「今回の本文」だけを空にし、それ以外のテキスト、VOICEVOXの共通設定とキャラの話者・スタイル、説明キャラと配置を引き継ぐ。個別アクセントは含めない。全体複製ではなく、新しいモデルへ許可した入力項目だけを設定する。

| 対象 | コピーする内容 |
| --- | --- |
| 題名 | 題名入力 |
| 台本入力 | 共通の出だし・共通の締め、その他の本文以外の文章区分。今回の本文は空欄 |
| 総評 | 文章・字幕・読み・見出し・評価項目名の入力文字。評価点・チャート方式・総評の有無選択・役番号は初期値 |
| 締め設定 | 題名の入力文字と作品名への連動。画像・表示秒数・回避領域は初期値 |
| VOICEVOX | 共通の速度・音高・抑揚・音量・前後の無音長。キャラごとの話者UUID・話者名・スタイルIDと名称 |
| 説明キャラ | 登録済みキャラへの選択参照と名前・形式。元のキャラ素材を複製しない |
| 配置 | x・y・幅・高さ・左右反転。画面外の座標も保持 |

生成音声・LAB・詳細query・個別アクセント・セリフごとの読み変更・音声エフェクト・配役済みセリフ・シーン・背景・サムネイル・末尾カード・BGM・調査情報・投稿情報・出力先・プレビュー/動画キャッシュ・動画設定・レイアウト方式・台本種類・確認状態は引き継がない。新しい作成/更新日時を記録し、到達済み工程も題名へ戻す。コピーした配置は、その後のキャラ選択・レイアウト・配置工程でも保持する。

締めの題名が作品名の自動設定なら、コピー後に作品名を入力し直すと締めの題名も更新する。既に作られた動画用の締めカードも同じ題名へ更新し、画像・セリフ・音声は保持する。独自に入力した見出しや、表示を消すための空欄は変更しない。`closingData.titleFollowsProject`に連動の有無を保存し、作品名を一度空にして保存・再開しても連動を維持する。題名を手で変更すると、作品名と一致する時だけ連動へ戻る。旧形式は空でない締め題名と作品名が一致する場合だけ連動と判定する。

話者・スタイルはコピー元台本で現在使用中の配役の値を優先し、配役がなければ選択キャラの保存済み設定を使う。新しい配役を準備する際、既存の共通処理で適用する。共通音声設定は既存の`scriptWizard.voice.commonSettings`に保存する。セリフがまだない前工程では設定だけの保存を許可し、配役を準備した時に新しい選択セリフを設定する。存在しないセリフを確定済みとは扱わない。

現在の台本に未保存の入力がある場合は入力を保持し、保存後のコピーを案内する。音声ジョブや配置操作中も切り替えない。コピー元の読込・UIDフォルダー・状態を検査し、読込中の外部更新を検出する。コピー先の保存が成功してから現在の台本を切り替える。保存済みの段階式台本が対象で、従来動画作品と読込不可の項目はコピーしない。

GUIとパイプは`TRigmWizardWorkspace.CopyScriptDraft`と`CreateScriptCopy`を共用する。パイプは`app-script-copy`へ`{"path":"Projects/<元UID>/project.rigmovie"}`を送り、新しい台本の状態を受け取る。成功後は返された新しいprojectId/revisionを使う。元台本のIDをそのまま新台本へ送らない。
