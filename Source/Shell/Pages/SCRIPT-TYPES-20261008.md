# 台本の種類と保存識別

題名画面の「台本の種類」コンボボックスから選ぶ。選択はGUIとパイプで共通の台本データへ反映し、通常の保存・工程選択・終了時保存で作品ファイルに残す。題名やファイル名に種類名を埋め込まず、固定IDで識別する。

| 表示名 | 保存するID |
| --- | --- |
| アニメ批評 | `anime-review` |
| 漫画紹介 | `manga-introduction` |
| アニメ（最初） | `anime-opening` |
| アニメ（最後） | `anime-closing` |
| アニメ（順位） | `anime-ranking` |

保存先は`.rigmovie`内の`scriptWizard.scriptType`。文字列の表示名やコンボボックスの番号は保存しない。

```json
{
  "scriptWizard": {
    "format": "RIGMMaker.ScriptWizard",
    "schemaVersion": 1,
    "titleInput": "作品の紹介",
    "scriptType": "manga-introduction"
  }
}
```

新規台本も旧台本も、選択するまでは未設定。旧ファイルにフィールドがなくても読み込みを拒否せず、作品名やセリフから種類を推測して付けない。種類の選択を新しい次工程への必須条件にはしていない。既存のアニメ批評・漫画紹介の間の分類変更では、原稿・配役・音声・画像・工程の完了状態を変更しない。アニメ（最初）・アニメ（最後）は工程を変える共通構成なので、新規の空台本の題名画面で選ぶ。入力済みの台本・素材・総評や締めの下書きがある作品との構成変更は拒否し、内容を保持する。

## 1シーンの共通構成

新規台本の題名画面で「アニメ（最初）」または「アニメ（最後）」を選ぶ。それぞれ導入のセリフのみ、締めのセリフのみを使う。外部台本の読み込みは不要で、取り込み操作は表示しない。題名→キャラ選択→レイアウト→配置→セリフ入力→台本確認→配役→字幕→音声→音声エフェクト→シーン割当→画像→動画編集と進む。内部の安定した工程ID・従来の段階番号は保持するため、工程リストの番号は途中を飛ばす。

セリフ入力・確認には使用する区分だけを表示する。作品情報・採点・総評・従来の締め画像設定は要求しない。複数行や空行があるセリフも1つのシーンへまとめ、シーン割当で分割しない。通常の配役・字幕・読み・音声確認は維持し、1シーンの画像要望・画像・補足・名前と任意の共通背景を編集できる。内容の人間による確定は必要。必須サムネイルと末尾10秒のカードはこの2種類には付けない。

保存・再開時も構成IDを保持する。既存の台本コピーでこの2種類をコピーした場合は、新しい作品IDに構成と共通のセリフを引き継ぐ。素材・音声・確定状態のコピーは既存の台本コピーの規則に従い、コピー元は上書きしない。共通構成を選び直して繰り返し作成することもできる。順位構成の改修や動画結合は今回の対象外。

隔離検証は `Source/Diagnostics/DotsCodexProbe/SingleScenePresetCheck.dpr`。同フォルダの `Build-SingleScenePresetCheck.ps1 -OutputRoot <隔離出力先>` で本編dprojの検索パスを使用してコンパイルする。検証EXEの第1引数にはまだ存在しない所有出力フォルダを渡す。GUI選択・保存・再編集・1シーン制約・通常の動画編集セッションへの受渡しを確認する。音声受渡しは無音WAVとfixture専用の確認済みメタデータによるもので、実際の音声生成・試聴やMP4出力を確認したものではない。通常EXEは起動しない。実施結果は開発履歴を参照する。

## アニメ（順位）の構成

新規の空台本の題名画面で「アニメ（順位）」を選ぶ。1作品の順位紹介パートを作り、全体の導入・締めや末尾サムネイルは入れない。工程は台本入力→総評入力→台本確認→既存の配役・字幕・音声・素材・動画編集へ進む。作品の実調査、画像生成、動画連結は自動実行しない。

台本入力には順位（1～999の整数）・作品タイトル・原作者・アニメ制作会社・OP/EDの曲名とアーティストの表を置く。情報は手入力し、原作なし・曲なし・未確認をそのまま記入できる。空欄は未確認として表示し、固有名詞を推測で補わない。順位の初期値は1。自動セリフと一致する間だけ順位変更に追従し、手で直したセリフは上書きしない。画面の順位表示と手動セリフの一致は入力画面で確認する。同順位の扱いは今回実装しない。

| 台本入力の区分 | 動画での扱い |
| --- | --- |
| 順位 | 背景画像・共通背景・人物・字幕を描かず、黒一色の全面に大きな白文字「第○位」。順位のセリフは通常の音声として流す。画像生成は要求しない |
| 作品タイトル・概要 | タイトルのセリフと概要の複数発話を同じ1シーンへ配置。大きな縁取りタイトルを継続表示し、任意でタイトル画像を設定できる。概要だけ別画面へ切り替えない |
| 登場人物 | 人物の説明のセリフと任意の画像・補足 |
| 原作者・制作会社 | 入力した原作者・アニメ制作会社の表示と説明。空欄は未確認 |
| OP紹介・評価 | 曲名・アーティストを表示し、紹介・評価のセリフを入力 |
| ED紹介・評価 | 曲名・アーティストを表示し、紹介・評価のセリフを入力 |
| 作品総評 | 独立したアニメ専用チャートと総評のセリフ |

台本入力の6タブに各セリフを記入し、総評は次の総評入力で記入する。区分内の改行・空行で画面を分けず、シーン割当の手動分割・結合も行わない。登場人物・制作・OP/EDなどの任意区分はセリフが空ならシーンを作らない。順位・作品タイトル・概要のセリフは必須。通常の字幕・読み・音声確認は維持する。作品タイトル・概要に使う画像はその区分の全発話で同じまま。台本確認は全区分の一覧で、修正する場合は左の台本入力または総評入力へ戻る。

チャートの初期6項目は「物語・キャラクター・作画・演出・声の演技・音楽」、初期範囲0～5、初期形式レーダー。音楽にOP/EDの評価を含める想定。項目名は今回の初期案であり、漫画用5項目を変更しない。保存済みの既存作品の点数やチャートは一括変換しない。構成変更で入力済み作品を変形させず、新規台本で選ぶ。コピーでは新IDへ順位構成・作品情報・概要を引き継ぎ、元作品を変更しない。素材・生成音声・確定状態は従来のコピー規則に従う。

手入力のほか、題名画面から専用テンプレートを保存してファイル／クリップボードで取り込める。書式例は[アニメ順位テンプレート](../../../台本入力/アニメ順位テンプレート.txt)。専用の区分名を使い、「本文：」以降にセリフを書く。「字幕：」「読み：」のペアも可能（1ペアの字幕2000文字以内）。画像・表示の指示は本文の前へ記入するが、順位区分には設定しない。再取込ではファイルにない作品情報・点数を前回から流用せず、解析失敗時はSnapshotを破棄して元入力を保持する。既存のアニメ批評・漫画紹介の取り込み経路は維持する。

新規ソースはRigmAnimeRankingModel.pas、RigmAnimeRankingFrame.pas/dfm。既存の共通描画からプレビューと動画へ同じ順位・タイトル表示を渡す。AnimeRankingPresetCheck.dprはユーザー側コンパイル用の検証ソースで、今回コンパイル・実行していない。今回の実施範囲は静的確認のみであり、ビルド・GUI・実画像・音声・MP4の確認はユーザー側ビルド後に必要。
## パイプ

- `app-script-status`は`scriptType`、`scriptTypeName`、`scriptTypes`（IDと表示名の一覧）を返す。
- `app-script-list`の各作品にも`scriptType`と`scriptTypeName`を返す。既存の`kind: wizard|legacy|unreadable`は作品形式の識別なので変更しない。
- `app-schema`の`workspace`から`script-set-type`と`scriptTypes`を取得できる。
- `app-script-set-type`へ現在の`projectId`、`revision`、`scriptType`を渡す。既存の入力編集中・古いrevision・別作品の拒否を共用する。

```json
{
  "command": "app-script-set-type",
  "args": {
    "projectId": "現在の作品ID",
    "revision": 123,
    "scriptType": "anime-review"
  }
}
```

選択可能なID以外や非文字列は拒否する。空文字は未設定へ戻す。同じIDの再指定は変更せず、revisionも増やさない。変更はアプリ内の未保存状態で、保存は`app-script-save`またはGUIの通常保存を使う。

保存済みの未知の種類は、64文字以内の小文字英数字・単独ハイフン（先頭は英字、末尾はハイフン不可）なら保持する。旧版の題名画面では「未対応の種類（ID）」として表示し、題名だけの編集・保存で別の種類へ置換しない。これは種類の分類であり、画像の画風・ジャンル・シリーズ設定や、校正の作品情報UIを追加したものではない。
