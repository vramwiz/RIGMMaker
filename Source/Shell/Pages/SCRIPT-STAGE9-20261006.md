## 操作と登録

この工程はVOICEVOXの調整だけを行う。原稿は原稿工程、表示字幕は字幕工程、声の人物は配役工程へ集約し、同じ編集欄を後工程へ重複配置しない。大きな読み・字幕欄、URL入力、人物の再選択、重複ツールバーを除去し、アクセント・モーラ音高・子音/母音長の3つを同じページ内で上から順に並べる。各段はアクセントと同程度の高さに固定し、縦に足りない時だけスクロールする。アクセントの文字幅・句間隔を基準に音高の列位置を揃え、子音と母音は同じモーラ列の中に並べる。3段の横スクロールも連動する。縦スクロールがある時、調整ページの余白でのホイールは縦へ送り、バーや数値入力上の操作は各編集部品に残す。セリフ一覧は構成変更時だけ再構築し、通常の表示更新は変更した行の値だけを反映する。基本6値の設定だけは別ページに残す。ツールバーは調整・基本設定・試聴の3ボタンとする。

↑↓でセリフを選択し、「感情」にはその人物が持つ実際の感情だけを表示する。実際のノーマルを初期選択し、初期値用の別項目を作らない。初期値はノーマル（公開されていない人物は先頭の実状態）。選択した感情はCue.voiceStyleIdへ保存し、他のセリフや人物の既定値を変更しない。調整は直接操作でき、Ctrl+Enter / Escで入力を確定する。F5または調整ツールバーの再生で選択セリフを生成・試聴し、Shift+F5／左下ボタンで連続再生する。停止・取消は処理中だけ表示する。全セリフの現在入力に一致する音声が揃ったら、上部Next（チェック）で入力を確定し、音声確認完了・保存・次工程への移動を続けて行う。全セリフの音声確認完了ボタンは、移動せず確認だけを記録する場合にも使える。

VOICEVOXは保存済みEXEと通常のインストール先を自動確認し、見つからない・接続できない場合だけ実行ファイルの手動設定を表示する。人物は名前から推定せず、配役でUUIDごとに1候補を明示選択し、人物の既定styleをノーマルへ設定する。旧人物既定の非ノーマルは既存Cueへ移して実音声と解析を保持し、新規Cueをノーマルにする。人物・配役を変更したセリフは旧人物の状態を持ち越さない。

登録初期値の読込と保存APIは保持するが、この調整画面へ登録編集のボタンを重複配置しない。

新しいキャラ選択時に登録初期値を作品へコピーし、音声準備時に未割当Speakerだけへ適用する。既存の選択・Speaker・WAV/LABは保持し、旧作品を一括変更しない。接続先は作品側の値を保持する。RIGM原本を更新しない。登録ファイルの読込前後hash、保存時expected hash、同じファイルを扱う協調mutexと一時ファイルのatomic replaceで競合を検出する。外部変更があれば内容を残して保存を拒否し、再起動して再取得する。

## 読み・音声データ

Cueの `voiceReading` は表示字幕・元原稿・シーンから独立する。空は従来のtextへ戻す。`voiceSettings` は有限の数値だけを持ち、次の範囲を検査する。

| JSON項目 | 範囲 |
| --- | --- |
| speedScale | 0.5–2 |
| pitchScale | −0.15–0.15 |
| intonationScale / volumeScale | 0–2 |
| prePhonemeLength / postPhonemeLength | 0–5秒 |

読みは2000 UTF16以内。制御文字と不完全なサロゲートを拒否する。表示字幕・元原稿・配役fingerprintは変えず、音声fingerprintは実際の読み、Speaker、query、接続先から計算する。新フィールドがない旧データのfingerprintは変わらない。変更しない詳細編集ではrevisionとfingerprintを維持する。

従来の生成ジョブ・VOICEVOXライブラリを再利用し、cueIdを指定した生成は1セリフだけを対象とする。結果回収時にprojectId、最新の配役と音声fingerprintを照合する。取消・失敗・生成中の新しい読み変更では古い結果を採用しない。以前のWAV/LAB/秒数/keyを保持し、現在の入力と不一致なら旧音声状態にする。正常生成の実測秒数変更は後続へrippleする。

基本調整は話速・音高・抑揚・音量・開始/終了無音。2026-10-07にSyncroh2のアクセント句・句の読み・モーラ音高・子音/母音長・基本6スライダーをコピー採用した。従来の基本合成の実PCM確認記録と、今回未ビルド・未実行の詳細UI移植を区別する。人間の聴感評価は行っていない。
