# 台本制作の工程リスト

台本制作画面の最上部は「保存して台本管理へ」「保存」と現在の段階番号・工程名を表示する。共通ヘッダーの「ホームへ戻る／台本作成」はこの画面では表示しない。台本管理や他の画面へ移ると共通ヘッダーが復帰する。

左の工程リストで画面を切り替える。各項目は「第6段階  作品情報・掘り下げ確認」のように、段階番号と工程名を空白で区切った1行で表示する。現在の工程は青く表示する。幅は未到達を含む全工程の文字幅とDPIから算出し、一覧の縦・横スクロールバーは表示しない。高さ不足時はホイールや矢印・Home／Endでスクロールする。新規台本は題名だけを表示し、題名入力などの条件が整うと次の工程が追加される。到達済みの工程は戻って編集でき、前工程の変更で条件が失われた工程はリストに残して移動不可の色にする。独立した進む・戻るボタン、上部の工程アイコンは設けない。

次の工程を選ぶと、編集中の入力を確認し、内容と移動先を同じ保存処理で記録してから切り替える。戻って保存しても再開先は最後に進んだ工程を保つ。保存失敗や無効な入力では現在の画面と入力を保持する。「保存」は画面を切り替えず、「保存して台本管理へ」は入力確認と保存が成功してから管理画面を開く。

字幕から音声へ進む場合は字幕入力を確認し、音声からエフェクトへ進む場合は生成・最後までの再生を確認する。シーン割当の保存を飛ばさず、全シーンの確定と音声が揃うと「動画編集」が表示される。通常は第12段階の画像工程から直接動画編集へ進む。旧台本の総評なし／あり、総評音声から締めへの分岐も保持する。

2026-10-09の方針変更で、台本制作全工程のフォーカス・キー・マウス・IME入力から通信ロックを取得しない。互換APIのBeginScriptTextEdit／EndScriptTextEditは状態を変えず、app-script-statusのtextEditingは常にfalse。作品タイトルにフォーカスがあるままでも検索候補・概要・タイトルのパイプ更新を表示する。現在のprojectId／revision／要求ID／作品IDの照合、配置ドラッグ操作、音声ジョブの排他は維持する。

各画面の未確定数値や下書きの反映・検証と、人間の作品・画像の確定は引き続き区別する。台本の種類は任意で、分類だけを新しい進行必須条件にしない。

## 実装

- `RigmScriptNavigationModel.pas`に工程ID、移動先、リスト表示と可否、表示名を集約する。GUIとWorkspaceの次工程判定は同じ移動先を使う。
- `RigmScriptCreatorFrame.pas`に文字ボタン、工程リスト、右側の編集ホストを配置する。リストの内容が変わらない更新では入力フォーカスと一覧のスクロールを保つ。
- `RigmWizardWorkspace.ScriptStatus`は選択キャラの検査状態と空の台本文も進行条件へ反映し、入力値が変わった時にリストを再評価する。生成・再生中には次工程を解除しない。
- 保存形式とパイプコマンド名は変更しない。`app-script-next`は各工程の確認済み状態を要求し、テキスト入力フォーカスを進行条件にしない。

## 検証

`Source/Psd/Validation/ScriptNavigationCheck.dpr`を通常EXE・DCUとは別の出力へビルドする。通常RESを検証DPRと同名のRESとして専用フォルダへコピーして使う。起動例は次の通り。出力ルートは毎回新しい専用ディレクトリを指定する。

```text
ScriptNavigationCheck.exe <出力ルート> --data-root <出力ルート>/OwnedData --settings-dir <出力ルート>/OwnedSettings
```

41項目：条件付き表示と旧台本の分岐、題名からキャラへの実保存・移動、前工程への復帰、管理画面への保存・再開、無効な題名と外部変更による保存失敗時の入力保持、台本なしの表示更新、96/144/192 DPI、第12段階の12シーンと要望・補足文、右側の編集幅を確認した。画像・音声の確定条件の分岐は状態モデルの検証で、実ユーザー作品の確定を操作した結果ではない。

工程別の既存検証は`RigmScriptNavigationProbe.pas`を通して実リストを選択する。検証用のNext変数を製品の隠しボタンへつなぐことはしない。今回、既存の工程別検証すべての実行は行っていない。
