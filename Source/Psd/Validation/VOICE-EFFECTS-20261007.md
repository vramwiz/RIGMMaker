Run `python Source/Psd/Validation/Verify-VoiceEffects.py` from the repository or any directory. Seven tests passed on the staged source: all 100 UI/DSP/default setting names agree; malformed, duplicate and out-of-range settings are rejected by the contract checks; sparse/default settings have a canonical stamp; settings remain keyed by cue ID; all twenty kernels have the expected order and reset contract; source provenance and Delphi UTF-8 BOM/CRLF are intact; preview and final mix call the common DSP; isolated temporary WAV fixtures preserve the original source and verify ring-delay/output-gain numeric contracts.

These are static and isolated Python contract checks, not execution of Pascal DSP. No Delphi build, application launch/restart, executable replacement, or audio-device audition was performed. Runtime UI, driver/MCI behavior, and produced audio quality still need the user's normal build and manual verification.

Preview creates a unique PCM16 mono derived WAV under the project `Audio/Effects` folder using `CREATE_NEW`, holding a read lock on the original WAV during processing. A completed worker is accepted only for the current project, fixed cue ID, source and effect key. Cancelled workers remain bounded to one active worker per frame and have no queued UI callbacks. Row/stage/page changes and disposal stop the private MCI alias. Typed knob edits are explicitly validated for save/Next.

Adjustments use a 280 ms debounce, then offline processing. The current pass continues, and an accepted current result is used on the next loop. Processing can leave a gap between loops; this is not sample-accurate live DSP. The inherited movie PCM path is mono, so stereo-specific modes fall back to mono. Delay/reverb tails stop at the original line sample count to preserve the timeline and avoid spilling into another cue. Source-change detection while looping uses path, synthesis key, size and modification time; deliberate external edits preserving both size and timestamp are not detected until the next fresh Play or final reprocessing. Stored derived files are never trusted as a cross-session preview cache.
