# 動画プレビューの負荷改善（2026-10-10）

動画編集の自動プレビューで、描画ごとの素材読込と作品全体の状態判定を減らす。埋込みのEditorFrameと単独のMovieFormで共通の処理を使用する。

## 動作

- 再生時計はSession.SeekTo、再生・ジョブ表示はTransportStatusで更新する。毎回の時刻更新で工程診断、全素材の指紋、JSON形式の作品全体の状態を作らない。外部のstatus／seek命令の応答形式は維持する。
- 自動画面描画は表示領域の寸法で要求し、通常1280×720以内へ縮小する。縦横比が極端な作品はモデルの最小寸法を優先する。スナップショットの幅・高さは成功・失敗の両方で元へ戻す。MP4／AVI、明示的なPNGプレビューは元の出力寸法を使う。
- 合成描画にはCompositorのキャラ素材キャッシュを使い、使用しない旧方式のキャラをフレームごとに追加読込しない。場面画像は復号済みのPNGとして最大16件・概算64 MiBまで保持する。各ワーカーへ複製し、GDIのDCを共有しない。パス・ファイルサイズ・更新日時の変更で再読込する。
- 表示用の口パクは現在のセリフのPCMとエフェクト結果だけをキャッシュする。絶対時刻の開始サンプルと25 msの末尾無音を持ち、BGMは口を動かさない。音声・設定・ファイル更新で無効化する。長い動画が全体PCMの64 MiBキャッシュ上限を超えても、フレームごとに全音声を混合しない。
- 表示フレームの受取用Bitmapを再利用する。自動描画の作品指紋はrevision変更時と1秒ごとに照合し、外部素材の更新も検出する。明示的なプレビューの指紋は毎回更新する。
- 待機中の診断表示の確認は1秒間隔とし、位置履歴が同じなら素材指紋の再計算・保存を行わない。履歴は毎回読み、別の保存・画面が書き換えた値は追従する。BGMの混合・フェードは動画の長さを一度計算し、各音声サンプルで再計算しない。
