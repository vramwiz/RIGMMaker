# 投稿用タイトル・概要・親作品

動画編集の右側の先頭ページを投稿用情報へ置き換える。タイトルは1行の入力欄、概要は複数行のメモ、親作品は固定値の読取専用入力欄とし、それぞれにクリップボードへ全文を送るボタンを置く。従来のセリフ・字幕・話者・VOICEVOXの再設定欄は右側へ表示しない。場面・演技・BGM・診断は既存ページで利用できる。

## 初期値と編集

タイトルの初期値は `【ニコニコ漫画】ニコニコ漫画の作品を紹介する　<台本のタイトル>  #60 【2026年10月11日】` の形式。日付は台本の `scriptWizard.createdAt` をローカル日付へ変換し、旧作品は作品ファイルの作成日、新規の従来形式は当日を使う。連番は自動で増やさず、タイトル内を人間が編集する。編集後は作成日と入力内容を保存し、再表示・再開で初期値へ戻さない。

親作品は `sm33517192 nc256993` で固定する。

概要の初期値は第6段階で人間が確認した選択作品から、作品名・`作者:<作者名>`・ニコニコ漫画の作品URLを改行して組み立てる。作者とURLがない旧候補では、存在する情報だけを使う。未承認の候補は使用しない。例:

```text
猫と手
作者:色鳥こぼし
https://manga.nicovideo.jp/comic/77802
```

候補に独自の紹介文 `postingSummary` があれば、空行の後へ追加する。取得した公式あらすじを投稿文へ丸ごと転記しない。概要は自由に編集でき、「確認した作品情報を概要へ追加」は既存の入力を残して追記する。同じ情報が含まれる場合は重複追加しない。アプリからAIへ自動で依頼する機能は追加していない。Codexで作った紹介文を候補の `postingSummary` または概要欄へ反映できる。

## 保存と負荷

入力は `TRigmMovieSession.Execute('update-posting',args)` で直ちに作品モデルへ反映し、通常の作品保存と台本編集へ戻る操作で `.rigmovie` の `posting` オブジェクトとして保存する。`title/description/createdDate` を持ち、旧作品で未作成なら既定値を返す。タイトル1000文字、概要20000文字を上限とする。親作品は製品の固定値なので保存データへ重複して持たない。

更新には現在の `projectId/revision` と編集リースの照合が必要。入力のたびに作品全体をCloneしたり、タイムライン・プレビューを作り直したりしない。`posting` は動画描画キーから除外し、音声・再生確認も保持する。投稿文は映像のUndo/Redoとは独立し、映像の操作を取り消しても入力済み投稿文は残る。

書き出しやプレビュー中も入力できる。投稿文だけの変更では完了ジョブの回収先の版を進め、ワーカーのsnapshotは変更しない。その他の作品変更に対する古い結果の拒否は維持する。入力命令では完了ジョブを同期回収せず、通常のTickで回収する。

## 担当と検証

- `Studio/Model/RigmMoviePosting.pas`: 既定値・確認済み作品からの概要・保存値の検証。
- `Studio/Views/Editor/RigmMoviePostingFrame.pas`: 入力・3つのコピー・追記。実体は独立した子コントロール所有のTPanel。
- `Integrations/RigmNicoManga.pas`: 公開ページの取得と解析。第6段階の検索仕様は[作品情報](../../../Shell/Pages/SCRIPT-RESEARCH-20261009.md)を参照。
- `Source/Psd/Validation/Run-PostingCheck.ps1 -OutDir <新しい出力> -HtmlDir <保存済みHTMLのフォルダ>`: 実ページの記録を解析し、専用台本で入力・コピー・保存再開・音声と動画キー維持・Undo/Redo・プレビュー中の入力・実検索・遅延結果の拒否を確認する。HTMLは `niconico-sample.html` と `niconico-search.html`。ユーザーの実作品へ試験書込みをしない。
