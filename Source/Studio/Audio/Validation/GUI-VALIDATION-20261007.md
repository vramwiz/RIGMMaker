# Isolated effects GUI validation

`EffectsGuiProbe.dpr` creates its own VCL form, workspace, named pipe, settings folder, manuscript and two short synthetic PCM files. It never starts or changes the normal RIGMMaker executable, opens a user project, invokes VOICEVOX, or sends material to another service.

`Build-EffectsGuiProbe.ps1 -Configuration Debug -Run` copies the probe DPR and repository `RIGMMaker.res` into a unique temporary output folder before compiling. `-OutDir` selects an existing or new output parent outside the repository; the default is a new short Temp folder. The copied DPR/resource, build log, EXE, DCUs, fixtures, JSON reports and PNGs all stay below that output parent. Omit `-Run` to compile only. Delphi 37.0 `dcc64` was used for the recorded successful run. Build/run requires the applicable user authorization; this script does not change approval policy.

The latest successfully executed GUI version is `run-06` from 2026-10-07 19:57 UTC, with **4,676 passing assertions** and no exception. It covers all 20 effects at 96/144/192 PPI, both 1400×900 and 1024×650 client viewports, repeated DPI changes, scroll reachability, caption and native editor font bounds, normal playback and end, looping, changing settings during looping, stop, cue changes, leaving the stage, missing managed source and recovery, invalid pending numeric input, save/fresh reopen, and Next to scene assignment. It additionally passes PCM load/save and preview processing from a 353-character Unicode source, adopted-output preservation, unadopted-output cleanup, timestamp invalidation of preview/final-mix metadata, and managed source/effect copy and reopen at 265 characters. Original PCM hashes and manuscript fingerprint stayed unchanged. The prior `run-05` passed 4,650 assertions before those final extensions.

The valid `*-frame.png` images were produced by calling `Host.Frame.PaintTo(Bitmap.Canvas,0,0)` on a freshly allocated bitmap containing the existing live VCL frame and child state. This is a native VCL client render, **not a desktop screenshot**. Owned `PrintWindow` was unavailable or returned an untouched bitmap, and the form-level `PaintTo` image was incomplete. The direct frame rendering shows the real transport, knobs, graphs and waveform. Offscreen parent background painting can appear black; at high DPI, magenta outer canvas marks space not painted by the visible clipped frame. These margins do not prove desktop background or window chrome appearance.

The controlled long-path fixture keeps project JSON and atomic temporary paths below MAX_PATH while the source, preview and hashed managed WAV paths exceed it. `VoiceHeardKey` represents the audio confirmation, and `Job.KeepOutput` explicitly preserves an adopted unique derived WAV. Both latest product Debug/Release builds and the Debug GUI probe compiled successfully. Each denied operation was retried once with the subsequent user instruction to build and inspect the layout; both retries were approved. The owned GUI probe (PID3532) completed run-06 with exit0; no normal RIGMMaker or IDE process was started or stopped, and no normal application EXE was replaced.
